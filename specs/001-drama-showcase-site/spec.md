# Feature Specification: 短剧展示静态网站

**Feature Branch**: `001-drama-showcase-site`
**Created**: 2025-11-18
**Status**: Draft
**Input**: User description: "创建苹果官网风格的短剧展示静态网站,使用React+shadcn技术栈,数据来自duanju.json"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 浏览学习路线图概览 (Priority: P1)

作为一名教师用户,我想要访问网站后立即看到短剧剧本写作学习路线图的整体结构,以便快速了解学习内容的框架和阶段划分。

**Why this priority**: 这是网站的核心价值所在,用户必须首先能看到完整的学习路线图才能继续深入了解具体内容。这是最小可行产品(MVP)的基础功能。

**Independent Test**: 用户打开网站首页,无需任何交互即可看到完整的学习路线图结构,包括所有阶段标题、预估时长和目标描述。可以独立验证页面是否正确加载和渲染duanju.json中的roadmap数据。

**Acceptance Scenarios**:

1. **Given** 用户首次访问网站, **When** 页面加载完成, **Then** 用户能看到标题"针对教师背景的短剧剧本写作变现学习路线图"和用户画像信息
2. **Given** 页面已加载, **When** 用户查看路线图, **Then** 显示所有学习阶段(1-6阶段),每个阶段包含标题、预估时长和核心目标
3. **Given** 用户在移动设备上访问, **When** 页面加载, **Then** 路线图以响应式布局正确显示,适配小屏幕
4. **Given** 用户切换到深色模式, **When** 主题切换完成, **Then** 所有内容以深色主题优雅呈现,保持良好的对比度和可读性

---

### User Story 2 - 查看模块详细内容 (Priority: P2)

作为一名教师用户,我想要点击某个学习阶段或模块后,能够查看该模块的详细内容(核心概念、学习路径、推荐资源等),以便深入了解具体学习内容和要求。

**Why this priority**: 在用户了解整体结构后,查看具体模块内容是自然的下一步需求。这让用户能够深入研究感兴趣的主题,是网站的核心交互功能。

**Independent Test**: 用户点击任意阶段卡片或模块标题,页面展开或导航到详细内容页,显示该模块的核心概念列表、学习路径建议和推荐资源。可以独立测试点击交互和内容渲染是否正确。

**Acceptance Scenarios**:

1. **Given** 用户在路线图页面, **When** 点击"阶段1:行业认知与思维转换", **Then** 展开或导航到详细页面,显示该阶段的所有模块和核心概念
2. **Given** 用户查看模块详情, **When** 滚动页面, **Then** 能看到该模块的学习目的、核心概念列表、学习路径和推荐资源
3. **Given** 用户在模块详情页, **When** 点击核心概念标题, **Then** 展开该概念的详细说明和示例
4. **Given** 用户完成查看, **When** 点击返回按钮, **Then** 流畅返回到路线图概览页面

---

### User Story 3 - 搜索和筛选内容 (Priority: P3)

作为一名教师用户,我想要通过关键词搜索或按阶段/类型筛选内容,以便快速找到我感兴趣的特定主题或模块,而不必逐个浏览所有内容。

**Why this priority**: 搜索和筛选功能可以提升用户体验,但不是核心功能。在MVP版本中,用户仍可以通过浏览找到所需内容,因此这是增强型功能。

**Independent Test**: 用户在搜索框输入关键词(如"霸总剧"),页面实时显示包含该关键词的所有模块和概念。可以独立测试搜索功能的准确性和性能。

**Acceptance Scenarios**:

1. **Given** 用户在网站首页, **When** 在搜索框输入"短剧类型", **Then** 实时显示所有包含该关键词的模块和概念,高亮匹配文本
2. **Given** 用户使用筛选器, **When** 选择"阶段1", **Then** 页面只显示阶段1相关的所有模块和内容
3. **Given** 用户输入不存在的关键词, **When** 搜索完成, **Then** 显示友好的"未找到结果"提示和搜索建议
4. **Given** 用户完成搜索, **When** 清空搜索框, **Then** 页面恢复显示完整的学习路线图

---

### User Story 4 - 查看核心概念详解 (Priority: P3)

作为一名教师用户,我想要查看每个核心概念的完整详细说明(包括定义、比喻、案例、学习路径等),以便深入理解该概念的内涵和应用方法。

**Why this priority**: 这是内容深度的体现,但需要在核心导航功能(P1、P2)完成后才有意义。用户可以先通过模块详情了解概况,再按需深入具体概念。

**Independent Test**: 用户点击核心概念卡片,进入该概念的详细页面,显示完整的概念说明,包括核心定义、比喻、工作原理、案例、优缺点、误解陷阱和学习路径。

**Acceptance Scenarios**:

1. **Given** 用户在模块详情页, **When** 点击"短剧产业链条"概念卡片, **Then** 展开或导航到该概念的详细页面
2. **Given** 用户查看概念详情, **When** 滚动页面, **Then** 依次看到核心定义、核心比喻、工作原理、现实案例、优缺点、常见误解和学习路径等完整内容
3. **Given** 概念详情包含代码或特殊格式内容, **When** 页面渲染, **Then** 正确显示Markdown格式的内容,包括代码块、表格、列表等
4. **Given** 用户阅读完概念详情, **When** 点击导航链接, **Then** 可以跳转到相关概念或返回上级页面

---

### User Story 5 - 收藏和进度跟踪 (Priority: P4)

作为一名教师用户,我想要能够收藏感兴趣的模块或概念,并标记已学习的内容,以便跟踪我的学习进度和快速访问重要内容。

**Why this priority**: 这是用户个性化功能,可以提升长期使用的体验,但不是静态网站的核心功能。可以在后续版本中考虑添加(需要本地存储或后端支持)。

**Independent Test**: 用户点击模块的收藏按钮,该模块被添加到"我的收藏"列表。用户点击"标记为已学习",该模块显示完成状态。刷新页面后,收藏和进度状态保持不变(使用localStorage)。

**Acceptance Scenarios**:

1. **Given** 用户查看某个模块, **When** 点击收藏按钮, **Then** 该模块被添加到收藏列表,按钮状态变为已收藏
2. **Given** 用户完成学习某个模块, **When** 点击"标记为已学习", **Then** 该模块显示完成标记,学习进度条更新
3. **Given** 用户收藏和标记了多个项目, **When** 刷新页面, **Then** 所有收藏和学习进度状态保持不变
4. **Given** 用户打开"我的收藏"页面, **When** 页面加载, **Then** 显示所有已收藏的模块和概念列表

---

### Edge Cases

- **数据加载失败**: 当duanju.json文件加载失败或数据格式错误时,网站显示友好的错误提示,建议用户刷新页面或联系管理员
- **JSON数据缺失**: 当某个阶段或模块缺少必要字段(如stage_title或module_title)时,系统使用占位符文本(如"未命名阶段")并在控制台记录警告
- **超长内容**: 当核心概念的详细说明超过10000字时,实现虚拟滚动或分页加载,避免页面性能问题
- **网络慢速**: 在慢速网络(2G/3G)环境下,首屏内容在5秒内加载完成,其他内容显示加载骨架屏
- **深色模式切换**: 用户在浏览过程中切换深色/浅色模式时,页面平滑过渡,不闪烁或重新加载
- **浏览器兼容性**: 在旧版浏览器(如IE11)中访问时,显示浏览器升级提示,建议使用现代浏览器
- **移动端手势**: 在移动设备上,支持左右滑动切换阶段,双击缩放图片或图表
- **搜索特殊字符**: 用户搜索包含特殊字符(如括号、引号)的关键词时,搜索功能正常工作,不会报错
- **空数据状态**: 当某个阶段暂无模块数据时,显示"内容即将上线"的占位提示
- **并发访问**: 多个用户同时访问网站时,每个用户的收藏和进度数据相互独立,不会混淆

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 网站MUST从duanju.json文件加载所有内容数据,包括标题、用户画像、学习路线图、阶段、模块和核心概念
- **FR-002**: 网站MUST在首页显示完整的学习路线图结构,包括标题、用户画像、所有学习阶段的标题、预估时长和目标
- **FR-003**: 用户MUST能够点击学习阶段查看该阶段的详细信息,包括所有模块、核心概念和学习资源
- **FR-004**: 用户MUST能够点击模块查看该模块的详细内容,包括模块目的、核心概念列表、学习路径和推荐资源
- **FR-005**: 用户MUST能够点击核心概念查看该概念的完整详细说明,包括定义、比喻、案例、学习路径等所有子字段
- **FR-006**: 网站MUST支持响应式设计,在移动端(< 640px)、平板(640px-1024px)和桌面端(> 1024px)都能正常显示和交互
- **FR-007**: 网站MUST支持深色和浅色两种主题模式,用户可以手动切换,系统默认根据浏览器/系统偏好设置主题
- **FR-008**: 网站MUST使用苹果官网风格的设计,包括极简主义布局、充足留白、流畅动画和优雅的字体排版
- **FR-009**: 所有页面过渡和交互动画MUST流畅自然,过渡时长150-500ms,使用标准缓动函数
- **FR-010**: 网站MUST在数据加载失败时显示友好的错误提示,并提供重试或返回首页的选项
- **FR-011**: 用户MUST能够通过关键词搜索所有模块和核心概念,搜索结果实时显示并高亮匹配文本
- **FR-012**: 用户MUST能够按阶段筛选内容,只显示选定阶段的相关模块和概念
- **FR-013**: 网站MUST支持用户收藏模块和概念,收藏列表存储在浏览器本地存储中
- **FR-014**: 用户MUST能够标记模块为"已学习",学习进度存储在本地,页面显示完成百分比
- **FR-015**: 网站MUST正确渲染Markdown格式内容,包括标题、段落、列表、表格、代码块等
- **FR-016**: 推荐资源链接MUST可点击并在新标签页打开,内部链接在当前页面跳转
- **FR-017**: 网站MUST在数据字段缺失时使用合理的默认值或占位符,确保页面不会崩溃
- **FR-018**: 网站MUST在首屏内容加载时显示加载指示器,避免长时间白屏

### Key Entities

- **Roadmap(学习路线图)**: 表示整个学习路线图,包含标题、用户画像和多个学习阶段。关键属性:title(标题)、user_profile(用户画像)、roadmap(阶段数组)
- **Stage(学习阶段)**: 表示学习路线图的一个阶段,包含阶段编号、标题、目标、预估时长和多个模块。关键属性:stage(编号)、stage_title(标题)、stage_goal(目标)、estimated_duration(预估时长)、modules(模块数组)
- **Module(学习模块)**: 表示某个阶段内的一个学习模块,包含标题、目的、核心概念和推荐资源。关键属性:module_title(标题)、module_purpose(目的)、core_concepts(核心概念数组)、recommended_resources(推荐资源数组)
- **Concept(核心概念)**: 表示某个模块内的一个核心概念,包含标题和详细说明。关键属性:concept_title(标题)、concept_detail(详细说明,Markdown格式)
- **Resource(推荐资源)**: 表示学习资源,包含名称、描述和链接。关键属性:name(名称)、description(描述)、url(链接)
- **UserProfile(用户画像)**: 表示目标用户的背景信息,包含背景描述、技能水平和学习目标。关键属性:background(背景)、skill_level(技能水平)、learning_goal(学习目标)
- **UserProgress(用户进度)**: 表示用户的学习进度,包含已完成的模块列表和收藏列表。关键属性:completed_modules(已完成模块ID数组)、bookmarked_items(收藏项ID数组)。存储在localStorage中

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户访问网站后,首屏内容(路线图概览)在2秒内(4G网络)完全加载并可交互
- **SC-002**: 网站在Lighthouse性能审计中获得90分以上的性能评分
- **SC-003**: 95%的用户能够在首次访问时无需指导即可找到并查看任意阶段的详细内容
- **SC-004**: 用户从点击阶段到查看模块详情的交互响应时间低于300毫秒
- **SC-005**: 网站在移动端、平板和桌面端的核心功能(浏览、搜索、查看详情)完全可用,无布局错乱或功能缺失
- **SC-006**: 深色/浅色主题切换过渡时间低于200毫秒,且切换过程流畅无闪烁
- **SC-007**: 用户使用搜索功能时,输入关键词后200毫秒内返回搜索结果
- **SC-008**: 网站在慢速3G网络环境下,核心内容仍能在5秒内加载完成
- **SC-009**: 用户收藏和进度跟踪功能的数据准确率100%,刷新页面后状态保持不变
- **SC-010**: 90%的页面文本内容在深色和浅色模式下都具有足够的对比度(WCAG AA标准,对比度≥4.5:1)
- **SC-011**: 网站在主流浏览器(Chrome、Safari、Firefox、Edge最新两个版本)的兼容性达到100%,核心功能无差异
- **SC-012**: 用户从首页导航到任意深层内容(如某个核心概念详情)的点击次数不超过3次

## Assumptions

以下是在规范编写过程中做出的合理假设:

1. **数据格式稳定**: 假设duanju.json文件的数据结构稳定,不会频繁变更。如需调整结构,需要同步更新网站的类型定义和渲染逻辑
2. **单页应用**: 假设网站采用单页应用(SPA)架构,使用前端路由实现页面切换,无需后端服务器支持
3. **本地存储**: 用户进度和收藏功能使用浏览器localStorage实现,无需后端数据库。用户清除浏览器缓存会丢失数据
4. **无用户认证**: 假设网站为公开访问,无需用户注册、登录或权限管理
5. **静态部署**: 网站可以部署到静态托管服务(如Vercel、Netlify、GitHub Pages),无需服务器端渲染或API
6. **现代浏览器**: 主要支持现代浏览器(Chrome、Safari、Firefox、Edge最新两个版本),对IE11等旧浏览器仅提供基础功能或升级提示
7. **中文内容**: 假设所有内容为简体中文,暂不支持多语言切换
8. **图片资源**: 假设duanju.json中的推荐资源链接为外部URL,网站本身不托管图片或视频资源
9. **性能目标**: 假设网站主要在移动端和桌面端浏览器访问,网络环境为4G或更好。对于2G/3G网络,提供基础功能但可能影响体验
10. **数据规模**: 假设duanju.json文件大小在1MB以内,可以一次性加载。如数据量增大,需考虑分块加载或虚拟化渲染

## Out of Scope

以下功能明确不在本项目范围内:

1. **用户认证和账户管理**: 不实现用户注册、登录、密码重置等功能
2. **后端服务和API**: 不开发后端服务器,所有数据来自静态JSON文件
3. **数据库集成**: 不使用任何数据库,用户数据仅存储在浏览器本地
4. **多语言支持**: 不实现国际化(i18n)和多语言切换功能
5. **社交分享和评论**: 不实现分享到社交媒体、用户评论或讨论功能
6. **支付和电商功能**: 不实现课程购买、支付、订单管理等电商功能
7. **视频播放**: 不嵌入或托管视频内容,仅提供外部视频链接
8. **离线模式**: 不实现PWA离线访问功能(可在后续版本考虑)
9. **SEO优化**: 作为静态SPA,基础SEO有限,不实现服务端渲染(SSR)或预渲染
10. **数据导出**: 不实现将学习进度导出为PDF或其他格式的功能
11. **管理后台**: 不实现内容管理系统(CMS),内容更新通过直接编辑JSON文件完成
12. **A/B测试**: 不实现用户行为分析、A/B测试或实验功能
13. **实时协作**: 不支持多用户实时协作编辑或讨论功能

## Notes

- **设计灵感**: 网站设计应参考苹果官网的产品展示页面(如MacBook、iPhone),特别是Hero区域、卡片布局和动画效果
- **性能优化**: 由于duanju.json文件较大(902行),建议实现虚拟滚动或按需加载,避免一次性渲染所有内容
- **可访问性**: 虽然未明确要求,但建议遵循WCAG 2.1 AA标准,确保键盘导航、屏幕阅读器兼容等
- **未来扩展**: 如需支持用户协作或云同步进度,可以考虑集成Firebase或Supabase等BaaS服务
- **内容更新**: 建议在项目README中说明如何更新duanju.json文件和重新部署网站
